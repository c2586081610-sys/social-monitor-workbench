# 小红书评论「语音转写 + 图片分析」功能方案（MVP 专家团）

> 版本 v0.1｜2026-08-26｜背景：已实现小红书全量评论抓取（MediaCrawler + 日常 Edge CDP 绕过 461），
> 评论区含 10 条语音评论（全部为博主"长***德"语音回复）+ 15 条图片评论（持仓截图等）。

---

## 一、需求定义（PM 视角）

| 需求 | 现状 | 目标 |
|------|------|------|
| 语音评论 | 已标记 10 条（content 空），未处理 | 下载语音 → 中文转写 → 转写文字进报告 |
| 图片评论 | 已标记 15 条（URL 在 pictures），未下载 | 下载 → 嵌入 MD → 图片内容分析 |
| 报告集成 | xhs_comment_analyze.py 已出层级/置顶/排序 | 语音转写 + 图片分析结果进同一份报告 |

**边界**：语音只做转写（不识别说话人/情绪）；图片分析用 WorkBuddy 视觉能力（零 API）。

---

## 二、技术方案（架构师视角）

### 数据层：语音/图片 URL 获取

**关键问题**：MediaCrawler 的 store 丢弃了语音字段（content 空时无法区分语音/表情/贴纸），
且原始 comment API 的语音字段名待确认（调研中：voice / voiceUrl / audio 等）。

**方案对比**：

| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| A. patch MediaCrawler store | store 增加 voice 字段存储 | 抓取即存，链路完整 | 需知道字段名；改第三方 |
| B. 自研拦截原始响应 | Playwright 拦截 comment API → 完整字段落盘 | 字段全、可控、不动第三方 | 需 token 有效（浏览器 CDP 下可自动刷新） |
| C. 抓后补采 | MediaCrawler 抓完后再按 comment_id 补语音 URL | 复用现有数据 | 补采成本高 |

**推荐**：**B 为主**（拦截原始 comment 响应，落盘 voice/pictures 完整字段），
A 作为 MediaCrawler 抓取时的补充（patch store 存 voice）。

### 语音转写层（后端工程师视角）

```
语音 URL（xhscdn，m4a/mp3）→ curl_cffi 下载 → FunASR paraformer-zh 转写 → 文字 + 置信度
```

- **工具**：FunASR paraformer-zh（已装，用于视频转写，CPU 远超实时，短语音秒级）
- **批处理**：10 条语音逐条转写，batch_size=1，VAD 可选（短语音无需）
- **输出**：`{comment_id}.txt` + 转写文字并入报告
- **异常**：语音 URL 失效 → 标记"语音已失效"

### 图片层（前端/视觉工程师视角）

```
pictures URL → curl_cffi 下载 → comment_images/ → MD 嵌入 → WorkBuddy 读图分析
```

- 下载：多图逗号分隔解析，命名 `cmt_{序号}_{图序}.webp|jpg`
- MD：`![评论图](相对路径)` 嵌入报告/笔记
- 分析：WorkBuddy 多模态读图 → 文字描述（持仓截图 → 识别基金/金额等）→ 进报告"图片分析"栏

---

## 三、实施步骤（后端工程师视角）

1. **字段确认**（30 分钟）：token 有效窗口内拦截 comment API，确认语音字段名（voice?）
2. **数据补采**（30 分钟）：拦截落盘 6a694aff 完整字段（voice/pictures）→ 语音 URL 提取
3. **语音下载+转写**（1 小时）：下载 10 条语音 → FunASR 转写 → 校验
4. **图片下载**（20 分钟）：15 条图片评论 → comment_images/
5. **报告集成**（40 分钟）：xhs_comment_analyze.py 扩展（语音转写文字 + 图片引用 + 图片分析）
6. **工具固化**（30 分钟）：xhs_voice_pic.py（一键：抓字段→下载→转写→分析→报告）

**总工时**：约 3-4 小时（含验证）

## 四、风险与对策

| 风险 | 对策 |
|------|------|
| 语音字段名不确定 | 先拦截确认（方案 B 天然拿全字段） |
| token 时效（20-30 分钟） | 日常 Edge CDP 下页面加载自动刷新会话；抓取脚本先开页面再抓 |
| 语音转写效果（博主口音/短语音） | paraformer 中文优化；短语音可拼批处理 |
| 图片分析准确度 | WorkBuddy 多模态直接读图，持仓类截图识别率高 |
| 461 风控 | 已绕过（日常 Edge CDP）；保持随机间隔 |
