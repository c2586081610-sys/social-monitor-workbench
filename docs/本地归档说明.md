# 本地作品归档

## 固定整理规则

新作品放在 `media/分组/博主/发布时间_平台_标题_作品ID/`。时间使用作品实际发布时间，显示时区为北京时间（`Asia/Shanghai`）；不知道发布时间时明确标注未知。平台显示名包括哔哩哔哩、抖音、小红书、X 和微信公众号；下载或查询能力以该平台已有适配器为准。

已有作品沿用原媒体目录和文件名。改变分组、博主或核对信息只更新归档记录和清单，不移动媒体。历史作品可以没有监控流水线中的 Work 记录，同一 Work 的多个本地副本也分别登记。

每个作品目录生成 `作品信息.csv`、`作品信息.json`、`作品信息.md`。所属目录和归档根分别生成 `合集清单.csv`、`归档总清单.csv`。CSV 使用 UTF-8 BOM，可用 Excel 打开；JSON 保留原文字与核对依据。

旧 `全部作品信息.csv` 保留原有每媒体文件行和附加列。人工挑选的旧合集只更新原成员，不会扩充成博主全部作品。

## 时间和来源

发布时间来自平台证据、可信本地采集数据或人工核对，并保留秒、分钟或日期精度。下载完成时间只有下载器本次真实写入并验证媒体成功后才产生。文件创建时间、修改时间、扫描时间和数据库创建时间均不能代替这两种时间。

复用已登记媒体、重试转写或重新同步清单不会更新下载完成时间。无媒体的纯文本作品没有下载完成时间。历史作品没有下载凭据时保留未知值；平台查询失败时保留已有可信信息，并显示待核实、冲突或失败状态。

## 网页入口

“本地归档”按平台、博主、分组、根目录、关键词和核对状态查找作品。时间筛选可以选择发布时间或下载完成时间，日期范围按北京时间解释，结束日期包含当天；可包含未知时间或只看未知时间。

“导出 CSV”导出当前筛选命中的全部记录，不受当前页和每页条数限制。作品详情可查看来源、精度、相对目录、登记媒体和修订记录，下载单作品 CSV，刷新平台信息、人工修正或重试同步。

“扫描历史目录”只接受已配置根标识和根下相对目录。扫描任务记录进度并在 API 服务恢复后继续，不创建媒体下载任务，不重下载原文件。刷新、扫描及清单同步由 API 独立归档 Worker 处理，不依赖监控流水线是否启用。

## 配置与数据边界

默认根标识为 `media`（项目媒体根）和 `fitness`（工作区的 `健身` 目录）。其他根可在私有环境配置 `ARCHIVE_ROOTS` JSON 映射；`media` 始终使用 `MEDIA_ROOT`。网页只显示根标识和友好名称，不显示机器绝对路径。

归档页面的媒体文件访问与 CSV 导出使用已有 Bearer 认证。归档 API 只允许读取根下登记的文件；绝对路径、上级跳转、未知根和目录联接越界均拒绝。

下载完成后先提交真实完成时间、媒体清单和待同步意图，再写作品信息并转写。同步失败保留下载成果，重试只补写元信息。清单通过跨进程锁和同目录原子替换写入，从数据库完整快照重建。

公共仓库只包含源码、接口契约和通用说明。媒体母库、作品 CSV/JSON/Markdown、运行报告、数据库、登录凭据、私有根映射和日志保留在本地。历史批量补齐前备份数据库和已有信息文件，保留媒体哈希基线。
